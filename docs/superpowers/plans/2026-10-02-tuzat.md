# Tuzat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Программа Tuzat для Windows: исправление текста, набранного не в той раскладке, по горячей клавише (`Pause` — последнее слово, `Shift+Pause` — выделенный текст).

**Architecture:** Вся логика без Win32 лежит в `Tuzat.Core` и покрыта xUnit-тестами. `Tuzat.App` — тонкий слой WinForms: иконка в трее, хуки клавиатуры и мыши на отдельном потоке, `SendInput`, переключение раскладки, буфер обмена через Win32 API. Установщик — Inno Setup 6 для одного пользователя.

**Tech Stack:** .NET 10 (SDK 10.0.301), C#, WinForms, `LibraryImport` (P/Invoke), System.Text.Json, xUnit 2.9.3, Inno Setup 6, PowerShell.

**Spec:** `docs/superpowers/specs/2026-10-02-tuzat-design.md`

## Global Constraints

- Все команды выполняются из корня репозитория `C:\_Projects\Tuzat` в Git Bash, если не сказано другое.
- `TargetFramework`: `net10.0` для Core и тестов, `net10.0-windows` для App.
- `Nullable`, `ImplicitUsings`, `TreatWarningsAsErrors` включены для всех проектов через `Directory.Build.props`.
- NuGet-пакеты: в Core и App — ни одного. В тестах — только пакеты из шаблона `dotnet new xunit`.
- Комментарии в коде: на английском, одно короткое предложение, только «почему».
- Тексты для пользователя (меню, уведомления, ошибки настроек): на русском.
- Набранный и исправленный текст никогда не пишется на диск, в `crash.log` и в уведомления. Сетевых запросов нет.
- Имя exe: `Tuzat.exe`. Mutex: `Tuzat.SingleInstance`. Значение автозапуска: `Tuzat` в `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`.
- Настройки: `%AppData%\Tuzat\settings.json`. Crash log: `%LocalAppData%\Tuzat\crash.log`.
- Хоткеи по умолчанию: `Pause` и `Shift+Pause`. Раскладки по умолчанию: `00000409` и `00000419`. Задержка восстановления буфера обмена: 200 мс (от 50 до 2000).
- Все события `SendInput` помечаются `dwExtraInfo = 0x545A5401` (`InputHooks.InjectedMarker`). Хук пропускает только события с этой меткой.
- Win32 interop только через `LibraryImport`. `AllowUnsafeBlocks` включён только в App.

**Отличия от spec** (spec обновлён вместе с планом):
- Файл решения — `Tuzat.slnx`. Это формат по умолчанию в SDK 10.
- `KeyStroke` хранит ещё и `VirtualKey`: по нему `WordBuffer` определяет тип клавиши.
- Вместо отдельных `KeyboardHook` и `MouseHook` используется один класс `InputHooks`. Оба хука работают на одном выделенном потоке и используют один `WordBuffer`. Поток отдельный, потому что UI-поток ждёт смену раскладки и буфер обмена. Если хук-поток ждёт, Windows молча снимает хук.
- Свои события хук определяет по метке `dwExtraInfo`, а не по `LLKHF_INJECTED`. Иначе ввод от других программ (экранная клавиатура, AutoHotkey) рассинхронизирует буфер.
- Ожидание в UI-потоке идёт через `ThreadWait.Sleep`. Обычный `Thread.Sleep` блокирует уведомления владельцу буфера обмена, и чужой Ctrl+C зависает до конца ожидания.
- В Core добавлены `HotkeyBindings` и `HotkeyFilter`. Это логика хоткеев из хука, теперь её можно тестировать.
- Хоткей с печатаемой клавишей без Ctrl, Alt или Win запрещён: он мешает набору текста. `Ctrl+Pause` запрещён: Windows выдаёт для него другой код клавиши.

```csharp
namespace Tuzat.Core;

public enum KeyKind { Printable, Space, Backspace, Reset, Modifier, Ignore }

public static class KeyClassifier
{
    // Unknown keys reset the buffer: they may move the caret or type something we cannot replay.
    public static KeyKind Classify(int virtualKey) => virtualKey switch
    {
        VirtualKey.Space => KeyKind.Space,
        VirtualKey.Back => KeyKind.Backspace,
        >= 0x30 and <= 0x39 or >= 0x41 and <= 0x5A => KeyKind.Printable,
        >= 0xBA and <= 0xC0 or >= 0xDB and <= 0xDF or 0xE2 => KeyKind.Printable,
        VirtualKey.Shift or VirtualKey.Control or VirtualKey.Menu or VirtualKey.Capital
            or >= VirtualKey.LShift and <= VirtualKey.RMenu
            or VirtualKey.LWin or VirtualKey.RWin => KeyKind.Modifier,
        VirtualKey.Pause or VirtualKey.Snapshot or VirtualKey.NumLock or VirtualKey.Scroll
            or >= 0xAD and <= 0xB7 or 0xFF => KeyKind.Ignore,
        _ => KeyKind.Reset,
    };
}
```

```csharp
namespace Tuzat.Core;

public sealed class WordBuffer
{
    public const int MaxLength = 64;

    private readonly List<KeyStroke> _strokes = new(MaxLength + 1);
    private nint _window;

    public void OnKeyDown(KeyStroke stroke, bool hasCommandModifier, nint window)
    {
        if (window != _window)
        {
            _strokes.Clear();
            _window = window;
        }

        var kind = KeyClassifier.Classify(stroke.VirtualKey);
        if (kind is KeyKind.Modifier or KeyKind.Ignore) return;
        if (hasCommandModifier)
        {
            _strokes.Clear();
            return;
        }

        switch (kind)
        {
            case KeyKind.Printable:
                if (_strokes.Count > 0 && _strokes[^1].VirtualKey == VirtualKey.Space) _strokes.Clear();
                Add(stroke);
                break;
            case KeyKind.Space:
                Add(stroke);
                break;
            case KeyKind.Backspace:
                if (_strokes.Count > 0) _strokes.RemoveAt(_strokes.Count - 1);
                break;
            default:
                _strokes.Clear();
                break;
        }
    }

    public KeyStroke[] Snapshot() => _strokes.ToArray();

    public void Clear() => _strokes.Clear();

    // A run longer than MaxLength is not a word, so a partial replay would be wrong.
    private void Add(KeyStroke stroke)
    {
        _strokes.Add(stroke);
        if (_strokes.Count > MaxLength) _strokes.Clear();
    }
}
```

```csharp
namespace Tuzat.Core;

public enum LayoutSide { A, B }

public static class LayoutSideExtensions
{
    public static LayoutSide Opposite(this LayoutSide side) => side == LayoutSide.A ? LayoutSide.B : LayoutSide.A;
}

public sealed class LayoutMap
{
    private readonly Dictionary<char, char> _aToB = [];
    private readonly Dictionary<char, char> _bToA = [];

    // The first pair for a character wins, so the map stays one-to-one.
    public LayoutMap(IEnumerable<(char A, char B)> pairs)
    {
        foreach (var (a, b) in pairs)
        {
            if (a == b || _aToB.ContainsKey(a) || _bToA.ContainsKey(b)) continue;
            _aToB[a] = b;
            _bToA[b] = a;
        }
    }

    public bool IsOnSideA(char c) => _aToB.ContainsKey(c);

    public bool IsOnSideB(char c) => _bToA.ContainsKey(c);

    public bool TryMap(char c, LayoutSide from, out char mapped) =>
        (from == LayoutSide.A ? _aToB : _bToA).TryGetValue(c, out mapped);
}
```

```csharp
namespace Tuzat.Core;

public static class TextConverter
{
    // Characters present on both sides (like '.') or on neither side say nothing about the source.
    public static LayoutSide DetectSource(string text, LayoutMap map, LayoutSide currentSide)
    {
        int a = 0, b = 0;
        foreach (var c in text)
        {
            bool onA = map.IsOnSideA(c), onB = map.IsOnSideB(c);
            if (onA && !onB) a++;
            else if (onB && !onA) b++;
        }

        return a > b ? LayoutSide.A : b > a ? LayoutSide.B : currentSide;
    }

    public static string Convert(string text, LayoutMap map, LayoutSide source)
    {
        var chars = text.ToCharArray();
        for (int i = 0; i < chars.Length; i++)
        {
            if (map.TryMap(chars[i], source, out var mapped)) chars[i] = mapped;
        }

        return new string(chars);
    }
}
```

```csharp
public enum HotkeyModifiers { None = 0, Ctrl = 1, Alt = 2, Shift = 4, Win = 8 }

public enum HotkeyAction { FixLastWord, FixSelection }

public readonly record struct Hotkey(HotkeyModifiers Modifiers, int Key)
{
    public bool Matches(int key, HotkeyModifiers modifiers) => key == Key && modifiers == Modifiers;

public sealed record HotkeyBindings(Hotkey FixLastWord, Hotkey FixSelection)
{
    public HotkeyAction? Match(int key, HotkeyModifiers modifiers) =>
        FixLastWord.Matches(key, modifiers) ? HotkeyAction.FixLastWord
        : FixSelection.Matches(key, modifiers) ? HotkeyAction.FixSelection
        : null;
```

```csharp
using System.Diagnostics.CodeAnalysis;

namespace Tuzat.Core;

public static class HotkeyParser
{
    private static readonly Dictionary<string, HotkeyModifiers> ModifierNames = new(StringComparer.OrdinalIgnoreCase)
    {
        ["Ctrl"] = HotkeyModifiers.Ctrl,
        ["Control"] = HotkeyModifiers.Ctrl,
        ["Alt"] = HotkeyModifiers.Alt,
        ["Shift"] = HotkeyModifiers.Shift,
        ["Win"] = HotkeyModifiers.Win,
    };

    private static readonly Dictionary<string, int> KeyNames = BuildKeyNames();

    public static bool TryParse(string? text, out Hotkey hotkey, [NotNullWhen(false)] out string? error)
    {
        hotkey = default;
        if (string.IsNullOrWhiteSpace(text))
        {
            error = "пустое значение";
            return false;
        }

        var modifiers = HotkeyModifiers.None;
        int? key = null;
        foreach (var rawPart in text.Split('+'))
        {
            var part = rawPart.Trim();
            if (ModifierNames.TryGetValue(part, out var modifier))
            {
                if (modifiers.HasFlag(modifier))
                {
                    error = $"модификатор {part} указан дважды";
                    return false;
                }
                modifiers |= modifier;
            }
            else if (KeyNames.TryGetValue(part, out var code))
            {
                if (key is not null)
                {
                    error = "указано больше одной основной клавиши";
                    return false;
                }
                key = code;
            }
            else
            {
                error = $"неизвестная клавиша \"{part}\"";
                return false;
            }
        }

        if (key is not { } finalKey)
        {
            error = "нет основной клавиши";
            return false;
        }

        // Windows reports Ctrl+Pause as VK_CANCEL, so this hotkey would never fire.
        if (finalKey == VirtualKey.Pause && modifiers.HasFlag(HotkeyModifiers.Ctrl))
        {
            error = "Ctrl+Pause не поддерживается";
            return false;
        }

        if (KeyClassifier.Classify(finalKey) is KeyKind.Printable or KeyKind.Space
            && (modifiers & (HotkeyModifiers.Ctrl | HotkeyModifiers.Alt | HotkeyModifiers.Win)) == 0)
        {
            error = "клавиша без Ctrl, Alt или Win мешает набору текста";
            return false;
        }

        hotkey = new Hotkey(modifiers, finalKey);
        error = null;
        return true;
    }

    private static Dictionary<string, int> BuildKeyNames()
    {
        var names = new Dictionary<string, int>(StringComparer.OrdinalIgnoreCase)
        {
            ["Pause"] = VirtualKey.Pause,
            ["ScrollLock"] = VirtualKey.Scroll,
            ["Insert"] = VirtualKey.Insert,
            ["Space"] = VirtualKey.Space,
        };
        for (int i = 1; i <= 24; i++) names[$"F{i}"] = VirtualKey.F1 + i - 1;
        for (char c = 'A'; c <= 'Z'; c++) names[c.ToString()] = c;
        for (char c = '0'; c <= '9'; c++) names[c.ToString()] = c;
        return names;
    }
}
```

```csharp
namespace Tuzat.Core;

public enum KeyDecision { Pass, Swallow, Trigger }

// Fires a hotkey once per press and hides its auto-repeat and key-up from other apps.
public sealed class HotkeyFilter
{
    private volatile HotkeyBindings? _bindings;
    private int _heldKey = -1;

    public HotkeyBindings? Bindings
    {
        get => _bindings;
        set => _bindings = value;
    }

    public KeyDecision OnKeyDown(int key, HotkeyModifiers modifiers, out HotkeyAction action)
    {
        action = default;
        if (key == _heldKey) return KeyDecision.Swallow;
        if (_bindings?.Match(key, modifiers) is not { } match) return KeyDecision.Pass;

        _heldKey = key;
        action = match;
        return KeyDecision.Trigger;
    }

    public bool OnKeyUp(int key)
    {
        if (key != _heldKey) return false;
        _heldKey = -1;
        return true;
    }

    public void Reset() => _heldKey = -1;
}
```

```csharp
using System.Text.Json;

namespace Tuzat.Core;

public sealed record SettingsLoadResult(TuzatSettings Settings, IReadOnlyList<string> Errors);

public static class SettingsLoader
{
    public const string DefaultJson = """
        {
          "fixLastWord": "Pause",
          "fixSelection": "Shift+Pause",
          "layouts": ["00000409", "00000419"],
          "clipboardRestoreDelayMs": 200
        }
        """;

    // Users edit the file in Notepad, so comments and trailing commas are tolerated.
    private static readonly JsonSerializerOptions Options = new()
    {
        PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
        ReadCommentHandling = JsonCommentHandling.Skip,
        AllowTrailingCommas = true,
    };

    public static SettingsLoadResult LoadOrCreate(string path)
    {
        try
        {
            if (File.Exists(path)) return Parse(File.ReadAllText(path));

            Directory.CreateDirectory(Path.GetDirectoryName(path)!);
            File.WriteAllText(path, DefaultJson);
            return new SettingsLoadResult(TuzatSettings.Default, []);
        }
        catch (Exception e) when (e is IOException or UnauthorizedAccessException)
        {
            return new SettingsLoadResult(TuzatSettings.Default, [$"не удалось прочитать {path}: {e.Message}"]);
        }
    }

    public static SettingsLoadResult Parse(string json)
    {
        SettingsFile? file;
        try
        {
            file = JsonSerializer.Deserialize<SettingsFile>(json, Options);
        }
        catch (JsonException e)
        {
            return new SettingsLoadResult(
                TuzatSettings.Default,
                [$"неверный JSON (строка {e.LineNumber + 1}), используются значения по умолчанию"]);
        }

        file ??= new SettingsFile();
        var defaults = TuzatSettings.Default;
        var errors = new List<string>();

        var fixLastWord = ReadHotkey(file.FixLastWord, "fixLastWord", defaults.FixLastWord, errors);
        var fixSelection = ReadHotkey(file.FixSelection, "fixSelection", defaults.FixSelection, errors);
        if (fixLastWord == fixSelection)
        {
            errors.Add("fixLastWord и fixSelection совпадают, используются значения по умолчанию");
            fixLastWord = defaults.FixLastWord;
            fixSelection = defaults.FixSelection;
        }

        var (layoutA, layoutB) = ReadLayouts(file.Layouts, defaults, errors);
        var delay = ReadDelay(file.ClipboardRestoreDelayMs, defaults.ClipboardRestoreDelayMs, errors);

        return new SettingsLoadResult(new TuzatSettings(fixLastWord, fixSelection, layoutA, layoutB, delay), errors);
    }

    private static Hotkey ReadHotkey(string? text, string field, Hotkey fallback, List<string> errors)
    {
        if (text is null) return fallback;
        if (HotkeyParser.TryParse(text, out var hotkey, out var error)) return hotkey;

        errors.Add($"{field}: {error}");
        return fallback;
    }

    private static (string, string) ReadLayouts(string?[]? layouts, TuzatSettings defaults, List<string> errors)
    {
        if (layouts is null) return (defaults.LayoutA, defaults.LayoutB);
        if (layouts is [{ } a, { } b] && IsKlid(a) && IsKlid(b) && !a.Equals(b, StringComparison.OrdinalIgnoreCase))
        {
            return (a.ToUpperInvariant(), b.ToUpperInvariant());
        }

        errors.Add("layouts: нужны две разные раскладки в формате KLID, например \"00000409\"");
        return (defaults.LayoutA, defaults.LayoutB);
    }

    private static bool IsKlid(string value) => value.Length == 8 && value.All(char.IsAsciiHexDigit);

    private static int ReadDelay(int? value, int fallback, List<string> errors)
    {
        if (value is null) return fallback;
        if (value is >= TuzatSettings.MinRestoreDelayMs and <= TuzatSettings.MaxRestoreDelayMs) return value.Value;

        errors.Add($"clipboardRestoreDelayMs: нужно число от {TuzatSettings.MinRestoreDelayMs} до {TuzatSettings.MaxRestoreDelayMs}");
        return fallback;
    }

    private sealed class SettingsFile
    {
        public string? FixLastWord { get; set; }
        public string? FixSelection { get; set; }
        public string?[]? Layouts { get; set; }
        public int? ClipboardRestoreDelayMs { get; set; }
    }
}
```

```csharp
namespace Tuzat.App;

internal static class CrashLog
{
    private static readonly string LogPath = Path.Combine(
        Environment.GetFolderPath(Environment.SpecialFolder.LocalApplicationData), "Tuzat", "crash.log");

    public static void Install()
    {
        Application.SetUnhandledExceptionMode(UnhandledExceptionMode.CatchException);
        Application.ThreadException += (_, e) => Fail(e.Exception);
        AppDomain.CurrentDomain.UnhandledException += (_, e) => Fail(e.ExceptionObject as Exception);
    }

    private static void Fail(Exception? exception)
    {
        try
        {
            Directory.CreateDirectory(Path.GetDirectoryName(LogPath)!);
            // Only type and stack trace: an exception message could carry user text.
            File.AppendAllText(
                LogPath,
                $"{DateTime.Now:O} {exception?.GetType().FullName}{Environment.NewLine}{exception?.StackTrace}{Environment.NewLine}{Environment.NewLine}");
        }
        catch (Exception e) when (e is IOException or UnauthorizedAccessException)
        {
            // The message box below is still shown; a missing log must not hide the crash.
        }

        MessageBox.Show(
            $"Tuzat остановлен из-за ошибки.{Environment.NewLine}Подробности: {LogPath}",
            "Tuzat",
            MessageBoxButtons.OK,
            MessageBoxIcon.Error);
        Environment.Exit(1);
    }
}
```

```csharp
        using var bitmap = new Bitmap(size, size);
        using (var graphics = Graphics.FromImage(bitmap))

            graphics.DrawString("T", font, Brushes.White, new RectangleF(0, 0, size, size), format);
        }

        nint handle = bitmap.GetHicon();
        try
        {
            using var temporary = Icon.FromHandle(handle);
            return (Icon)temporary.Clone();
        }
        finally
        {
            DestroyIcon(handle);
        }
```

```csharp
using System.Diagnostics;
using Tuzat.Core;

namespace Tuzat.App;

internal sealed class TrayApp : ApplicationContext
{
    private static readonly string SettingsPath = Path.Combine(
        Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "Tuzat", "settings.json");

    private readonly Icon _activeIcon = TrayIcons.Create(paused: false);
    private readonly NotifyIcon _tray;
    private readonly ToolStripMenuItem _autostartItem;

    public TrayApp()
    {
        _autostartItem = new ToolStripMenuItem("Автозапуск", null, (_, _) => ToggleAutostart()) { Checked = Autostart.IsEnabled };
        var menu = new ContextMenuStrip();
        menu.Items.AddRange(new ToolStripItem[]
        {
            _autostartItem,
            new ToolStripSeparator(),
            new ToolStripMenuItem("Открыть настройки", null, (_, _) => OpenSettings()),
            new ToolStripMenuItem("Перечитать настройки", null, (_, _) => ApplySettings()),
            new ToolStripSeparator(),
            new ToolStripMenuItem("Выход", null, (_, _) => ExitThread()),
        });
        _tray = new NotifyIcon { Icon = _activeIcon, Text = "Tuzat", ContextMenuStrip = menu, Visible = true };

        ApplySettings();
    }

    private void ApplySettings()
    {
        var errors = SettingsLoader.LoadOrCreate(SettingsPath).Errors;
        if (errors.Count == 0) return;
        _tray.ShowBalloonTip(10_000, "Tuzat: настройки", string.Join(Environment.NewLine, errors), ToolTipIcon.Warning);
    }

    private void ToggleAutostart()
    {
        try
        {
            Autostart.Set(!_autostartItem.Checked);
            _autostartItem.Checked = Autostart.IsEnabled;
        }
        catch (Exception e) when (e is UnauthorizedAccessException or System.Security.SecurityException or IOException)
        {
            _tray.ShowBalloonTip(5_000, "Tuzat", $"Не удалось изменить автозапуск: {e.Message}", ToolTipIcon.Error);
        }
    }

    private static void OpenSettings()
    {
        SettingsLoader.LoadOrCreate(SettingsPath);
        using var _ = Process.Start("notepad.exe", $"\"{SettingsPath}\"");
    }

    protected override void Dispose(bool disposing)
    {
        if (disposing)
        {
            _tray.Visible = false;
            _tray.ContextMenuStrip?.Dispose();
            _tray.Dispose();
            _activeIcon.Dispose();
        }

        base.Dispose(disposing);
    }
}
```

```csharp
    public static void Sleep(int milliseconds)
    {
        long deadline = Environment.TickCount64 + milliseconds;
```

```csharp
using Tuzat.Core;
using static Tuzat.App.Native.NativeMethods;

namespace Tuzat.App;

internal sealed class LayoutSwitcher
{
    private const int SwitchTimeoutMs = 200;

    private readonly nint _a;
    private readonly nint _b;

    private LayoutSwitcher(nint a, nint b) { _a = a; _b = b; }

    public static LayoutSwitcher? TryCreate(string klidA, string klidB, out string? error)
    {
        nint? a = FindInstalled(klidA);
        nint? b = FindInstalled(klidB);
        if (a is null || b is null)
        {
            error = $"раскладка {(a is null ? klidA : klidB)} не установлена в Windows, горячие клавиши отключены";
            return null;
        }

        error = null;
        return new LayoutSwitcher(a.Value, b.Value);
    }

    // A layout outside the pair counts as B, so the target becomes A.
    public LayoutSide SideOf(FocusTarget focus) =>
        GetKeyboardLayout(focus.ThreadId) == _a ? LayoutSide.A : LayoutSide.B;

    public void SwitchTo(FocusTarget focus, LayoutSide side)
    {
        nint target = side == LayoutSide.A ? _a : _b;
        if (GetKeyboardLayout(focus.ThreadId) == target) return;
        if (!PostMessage(focus.Window, WM_INPUTLANGCHANGEREQUEST, 0, target)) return;

        // The switch is asynchronous; replayed keys must not arrive before it.
        long deadline = Environment.TickCount64 + SwitchTimeoutMs;
        while (GetKeyboardLayout(focus.ThreadId) != target && Environment.TickCount64 < deadline)
        {
            ThreadWait.Sleep(10);
        }
    }

    // HKL values do not map to KLID strings directly, so each layout is activated briefly on this thread to read its name.
    private static unsafe nint? FindInstalled(string klid)
    {
        int count = GetKeyboardLayoutList(0, null);
        var layouts = new nint[count];
        fixed (nint* list = layouts) count = GetKeyboardLayoutList(count, list);

        nint original = GetKeyboardLayout(0);
        char* name = stackalloc char[KL_NAMELENGTH];
        try
        {
            for (int i = 0; i < count; i++)
            {
                if (ActivateKeyboardLayout(layouts[i], 0) == 0 || !GetKeyboardLayoutName(name)) continue;
                if (new string(name).Equals(klid, StringComparison.OrdinalIgnoreCase)) return layouts[i];
            }

            return null;
        }
        finally
        {
            ActivateKeyboardLayout(original, 0);
        }
    }
}
```

```csharp
using System.Runtime.InteropServices;
using Tuzat.Core;
using static Tuzat.App.Native.NativeMethods;

namespace Tuzat.App;

internal sealed class InputSender
{
    private const ushort LeftShiftScanCode = 0x2A;

    // Unassigned key: pressing it stops a lone Alt or Win release from opening a menu.
    private const int MenuMaskKey = 0xE8;

    private static readonly int[] Modifiers =
    [
        VirtualKey.LShift, VirtualKey.RShift, VirtualKey.LControl, VirtualKey.RControl,
        VirtualKey.LMenu, VirtualKey.RMenu, VirtualKey.LWin, VirtualKey.RWin,
    ];

    private readonly List<INPUT> _batch = [];

    // Held hotkey modifiers would otherwise turn Ctrl+C into Ctrl+Shift+C or change replayed letters.
    public bool ReleaseModifiers()
    {
        bool masked = false;
        foreach (var key in Modifiers)
        {
            if ((GetAsyncKeyState(key) & 0x8000) == 0) continue;
            if (!masked && key is VirtualKey.LMenu or VirtualKey.RMenu or VirtualKey.LWin or VirtualKey.RWin)
            {
                AddKey(MenuMaskKey, up: false);
                AddKey(MenuMaskKey, up: true);
                masked = true;
            }
            AddKey(key, up: true);
        }

        return Flush();
    }

    public bool Backspace(int count)
    {
        for (int i = 0; i < count; i++)
        {
            AddKey(VirtualKey.Back, up: false);
            AddKey(VirtualKey.Back, up: true);
        }

        return Flush();
    }

    // Scan codes are physical positions, so the new layout produces the right characters.
    public bool Replay(IReadOnlyList<KeyStroke> strokes)
    {
        foreach (var stroke in strokes)
        {
            if (stroke.Shift) AddScan(LeftShiftScanCode, extended: false, up: false);
            AddScan(stroke.ScanCode, stroke.IsExtended, up: false);
            AddScan(stroke.ScanCode, stroke.IsExtended, up: true);
            if (stroke.Shift) AddScan(LeftShiftScanCode, extended: false, up: true);
        }

        return Flush();
    }

    public bool Chord(int modifier, int key)
    {
        AddKey(modifier, up: false);
        AddKey(key, up: false);
        AddKey(key, up: true);
        AddKey(modifier, up: true);
        return Flush();
    }

    private void AddKey(int virtualKey, bool up) =>
        _batch.Add(Keyboard(
            (ushort)virtualKey,
            (ushort)MapVirtualKey((uint)virtualKey, MAPVK_VK_TO_VSC),
            up ? KEYEVENTF_KEYUP : 0));

    private void AddScan(ushort scanCode, bool extended, bool up) =>
        _batch.Add(Keyboard(
            0,
            scanCode,
            KEYEVENTF_SCANCODE | (extended ? KEYEVENTF_EXTENDEDKEY : 0) | (up ? KEYEVENTF_KEYUP : 0)));

    private static INPUT Keyboard(ushort virtualKey, ushort scanCode, uint flags) => new()
    {
        type = INPUT_KEYBOARD,
        u = new InputUnion
        {
            ki = new KEYBDINPUT { wVk = virtualKey, wScan = scanCode, dwFlags = flags, dwExtraInfo = InputHooks.InjectedMarker },
        },
    };

    // One SendInput call per step, so the user's own typing cannot land in the middle.
    private unsafe bool Flush()
    {
        if (_batch.Count == 0) return true;

        var inputs = CollectionsMarshal.AsSpan(_batch);
        uint sent;
        fixed (INPUT* pointer = inputs) sent = SendInput((uint)inputs.Length, pointer, sizeof(INPUT));
        bool complete = sent == inputs.Length;
        _batch.Clear();
        return complete;
    }
}
```

```csharp
using System.ComponentModel;
using System.Runtime.InteropServices;
using Tuzat.Core;
using static Tuzat.App.Native.NativeMethods;

namespace Tuzat.App;

// A dedicated thread: Windows silently removes a low-level hook whose thread is busy, and the UI thread waits often.
internal sealed class InputHooks : IDisposable
{
    public const nuint InjectedMarker = 0x545A5401;

    private const uint WmReinstall = WM_APP + 1;
    private const uint WmClear = WM_APP + 2;

    private readonly Action<HotkeyAction, KeyStroke[]> _onHotkey;
    private readonly WordBuffer _buffer = new();
    private readonly HotkeyFilter _filter = new();
    private readonly HookProc _keyboardProc;
    private readonly HookProc _mouseProc;
    private Thread? _thread;
    private uint _threadId;
    private nint _keyboardHook;
    private nint _mouseHook;
    private volatile bool _paused;

    // onHotkey runs on the hook thread and must return quickly.
    public InputHooks(Action<HotkeyAction, KeyStroke[]> onHotkey)
    {
        _onHotkey = onHotkey;
        _keyboardProc = KeyboardProc;
        _mouseProc = MouseProc;
    }

    public bool Paused
    {
        get => _paused;
        set
        {
            _paused = value;
            Post(WmClear);
        }
    }

    public void SetBindings(HotkeyBindings? bindings) => _filter.Bindings = bindings;

    public void Start()
    {
        int error = 0;
        using var ready = new ManualResetEventSlim();
        _thread = new Thread(() =>
        {
            _threadId = GetCurrentThreadId();
            PeekMessage(out _, 0, WM_USER, WM_USER, PM_NOREMOVE); // creates the message queue before anyone posts to it
            error = Install();
            ready.Set();
            if (error == 0) RunLoop();
        })
        { IsBackground = true, Name = "Tuzat hooks" };
        _thread.Start();
        ready.Wait();

        if (error != 0) throw new Win32Exception(error);
    }

    public void Reinstall() => Post(WmReinstall);

    public void Dispose()
    {
        if (_thread is null) return;
        Post(WM_QUIT);
        _thread.Join(TimeSpan.FromSeconds(1));
        _thread = null;
    }

    private void Post(uint message)
    {
        if (_threadId != 0) PostThreadMessage(_threadId, message, 0, 0);
    }

    private void RunLoop()
    {
        while (GetMessage(out var message, 0, 0, 0) > 0)
        {
            if (message.message == WmReinstall)
            {
                Uninstall();
                _filter.Reset();
                _buffer.Clear();
                Install();
            }
            else if (message.message == WmClear)
            {
                _buffer.Clear();
                _filter.Reset();
            }
        }

        Uninstall();
    }

    private int Install()
    {
        nint module = GetModuleHandle(null);
        _keyboardHook = SetWindowsHookEx(WH_KEYBOARD_LL, Marshal.GetFunctionPointerForDelegate(_keyboardProc), module, 0);
        if (_keyboardHook == 0) return Marshal.GetLastPInvokeError();

        _mouseHook = SetWindowsHookEx(WH_MOUSE_LL, Marshal.GetFunctionPointerForDelegate(_mouseProc), module, 0);
        if (_mouseHook != 0) return 0;

        int error = Marshal.GetLastPInvokeError();
        Uninstall();
        return error;
    }

    private void Uninstall()
    {
        if (_keyboardHook != 0) UnhookWindowsHookEx(_keyboardHook);
        if (_mouseHook != 0) UnhookWindowsHookEx(_mouseHook);
        _keyboardHook = 0;
        _mouseHook = 0;
    }

    private unsafe nint KeyboardProc(int nCode, nint wParam, nint lParam)
    {
        if (nCode >= 0 && HandleKey((int)wParam, *(KBDLLHOOKSTRUCT*)lParam)) return 1;
        return CallNextHookEx(0, nCode, wParam, lParam);
    }

    // Returns true when the key must be hidden from other apps.
    private bool HandleKey(int message, KBDLLHOOKSTRUCT key)
    {
        if (key.dwExtraInfo == InjectedMarker || _paused) return false;

        int virtualKey = (int)key.vkCode;
        if (message is WM_KEYUP or WM_SYSKEYUP) return _filter.OnKeyUp(virtualKey);

        var modifiers = CurrentModifiers();
        switch (_filter.OnKeyDown(virtualKey, modifiers, out var action))
        {
            case KeyDecision.Trigger:
                _onHotkey(action, _buffer.Snapshot());
                return true;
            case KeyDecision.Swallow:
                return true;
        }

        var stroke = new KeyStroke(
            virtualKey,
            (ushort)key.scanCode,
            (key.flags & LLKHF_EXTENDED) != 0,
            modifiers.HasFlag(HotkeyModifiers.Shift));
        _buffer.OnKeyDown(stroke, (modifiers & ~HotkeyModifiers.Shift) != 0, GetForegroundWindow());
        return false;
    }

    private nint MouseProc(int nCode, nint wParam, nint lParam)
    {
        if (nCode >= 0 && (int)wParam is WM_LBUTTONDOWN or WM_RBUTTONDOWN or WM_MBUTTONDOWN or WM_XBUTTONDOWN)
        {
            _buffer.Clear();
        }

        return CallNextHookEx(0, nCode, wParam, lParam);
    }

    private static HotkeyModifiers CurrentModifiers()
    {
        var modifiers = HotkeyModifiers.None;
        if (IsDown(VirtualKey.Shift)) modifiers |= HotkeyModifiers.Shift;
        if (IsDown(VirtualKey.Control)) modifiers |= HotkeyModifiers.Ctrl;
        if (IsDown(VirtualKey.Menu)) modifiers |= HotkeyModifiers.Alt;
        if (IsDown(VirtualKey.LWin) || IsDown(VirtualKey.RWin)) modifiers |= HotkeyModifiers.Win;
        return modifiers;
    }

    private static bool IsDown(int virtualKey) => (GetAsyncKeyState(virtualKey) & 0x8000) != 0;
}
```

```csharp
internal static class FixLastWordAction
{
    // The buffer is not cleared afterwards, so a second press converts the word back.
    public static void Run(KeyStroke[] strokes, LayoutSwitcher layouts, InputSender input)
    {
        if (FocusTracker.Current() is not { } focus || !input.ReleaseModifiers()) return;

{
```

```csharp
        Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData), "Tuzat", "settings.json");

    private readonly WindowsFormsSynchronizationContext _ui = new();
    private readonly Icon _activeIcon = TrayIcons.Create(paused: false);

    private readonly ToolStripMenuItem _pauseItem;
    private readonly ToolStripMenuItem _autostartItem;
    private TuzatSettings _settings = TuzatSettings.Default;
    private LayoutSwitcher? _layouts;

    public TrayApp()
    {
        // Hooks start first: if they fail, no tray icon is left behind.
        _hooks = new InputHooks((action, strokes) => _ui.Post(_ => Run(action, strokes), null));
        _hooks.Start();

        _pauseItem = new ToolStripMenuItem("Пауза", null, (_, _) => SetPaused(!_hooks.Paused));
        _autostartItem = new ToolStripMenuItem("Автозапуск", null, (_, _) => ToggleAutostart()) { Checked = Autostart.IsEnabled };
        var menu = new ContextMenuStrip();
        menu.Items.AddRange(new ToolStripItem[]
        {
            _pauseItem,
            _autostartItem,
            new ToolStripSeparator(),
            new ToolStripMenuItem("Открыть настройки", null, (_, _) => OpenSettings()),
            new ToolStripMenuItem("Перечитать настройки", null, (_, _) => ApplySettings()),
            new ToolStripSeparator(),
            new ToolStripMenuItem("Выход", null, (_, _) => ExitThread()),
        });
        _tray = new NotifyIcon { Icon = _activeIcon, Text = "Tuzat", ContextMenuStrip = menu, Visible = true };

        ApplySettings();

        SystemEvents.PowerModeChanged += OnPowerModeChanged;
        SystemEvents.SessionSwitch += OnSessionSwitch;
    }

    private void Run(HotkeyAction action, KeyStroke[] strokes)
    {
        if (_layouts is null) return;

        switch (action)
        {
            case HotkeyAction.FixLastWord:
                FixLastWordAction.Run(strokes, _layouts, _input);
                break;
        }
    }

    private void ApplySettings()
    {
        var result = SettingsLoader.LoadOrCreate(SettingsPath);
        var errors = result.Errors.ToList();
        _settings = result.Settings;
        _layouts = LayoutSwitcher.TryCreate(_settings.LayoutA, _settings.LayoutB, out var layoutError);
        if (layoutError is not null) errors.Add(layoutError);

        _hooks.SetBindings(_layouts is null ? null : _settings.Bindings);
        if (errors.Count > 0)
        {
            _tray.ShowBalloonTip(10_000, "Tuzat: настройки", string.Join(Environment.NewLine, errors), ToolTipIcon.Warning);
        }
    }

    private void SetPaused(bool paused)
    {
        _hooks.Paused = paused;
        _pauseItem.Checked = paused;
        _tray.Icon = paused ? _pausedIcon : _activeIcon;
        _tray.Text = paused ? "Tuzat — пауза" : "Tuzat";
    }

    private void ToggleAutostart()
    {
        try
        {
            Autostart.Set(!_autostartItem.Checked);
            _autostartItem.Checked = Autostart.IsEnabled;
        }
        catch (Exception e) when (e is UnauthorizedAccessException or System.Security.SecurityException or IOException)
        {
            _tray.ShowBalloonTip(5_000, "Tuzat", $"Не удалось изменить автозапуск: {e.Message}", ToolTipIcon.Error);
        }
    }

    private static void OpenSettings()
    {
        SettingsLoader.LoadOrCreate(SettingsPath);
        using var _ = Process.Start("notepad.exe", $"\"{SettingsPath}\"");
    }

    // Windows can drop low-level hooks after sleep or a locked session.
    private void OnPowerModeChanged(object? sender, PowerModeChangedEventArgs e)
    {
        if (e.Mode == PowerModes.Resume) _hooks.Reinstall();
    }

    private void OnSessionSwitch(object? sender, SessionSwitchEventArgs e)
    {
        if (e.Reason == SessionSwitchReason.SessionUnlock) _hooks.Reinstall();
    }

    protected override void Dispose(bool disposing)
    {
        if (disposing)
        {
            SystemEvents.PowerModeChanged -= OnPowerModeChanged;
            SystemEvents.SessionSwitch -= OnSessionSwitch;
            _hooks.Dispose();
            _tray.Visible = false;
            _tray.ContextMenuStrip?.Dispose();
            _tray.Dispose();
            _activeIcon.Dispose();
            _pausedIcon.Dispose();
            _ui.Dispose();
        }

        base.Dispose(disposing);
    }
}
```

```csharp
using Tuzat.Core;
using static Tuzat.App.Native.NativeMethods;

namespace Tuzat.App;

internal static class LayoutMapBuilder
{
    // Keeps dead-key state intact (Windows 10 1607+), so building the map never breaks the user's next accent.
    private const uint DoNotChangeKeyboardState = 0x4;

    // Number row, three letter rows and the extra key next to left Shift (OEM_102).
    private static readonly ushort[] ScanCodes =
        [0x29, .. Range(0x02, 0x0D), .. Range(0x10, 0x1B), 0x2B, .. Range(0x1E, 0x28), .. Range(0x2C, 0x35), 0x56];

    // Unshifted keys go first, so lower-case pairs win over shifted ones in LayoutMap.
    public static LayoutMap Build(nint layoutA, nint layoutB)
    {
        var pairs = new List<(char, char)>();
        foreach (bool shift in new[] { false, true })
        {
            foreach (var scanCode in ScanCodes)
            {
                if (TryGetChar(layoutA, scanCode, shift, out var a) && TryGetChar(layoutB, scanCode, shift, out var b))
                {
                    pairs.Add((a, b));
                }
            }
        }

        return new LayoutMap(pairs);
    }

    private static unsafe bool TryGetChar(nint layout, ushort scanCode, bool shift, out char result)
    {
        result = default;
        uint virtualKey = MapVirtualKeyEx(scanCode, MAPVK_VSC_TO_VK, layout);
        if (virtualKey == 0) return false;

        byte* state = stackalloc byte[256];
        new Span<byte>(state, 256).Clear();
        if (shift) state[VirtualKey.Shift] = 0x80;

        char* buffer = stackalloc char[4];
        if (ToUnicodeEx(virtualKey, scanCode, state, buffer, 4, DoNotChangeKeyboardState, layout) != 1) return false;

        result = buffer[0];
        return !char.IsControl(result);
    }

    private static IEnumerable<ushort> Range(int first, int last) =>
        Enumerable.Range(first, last - first + 1).Select(i => (ushort)i);
}
```

`src/Tuzat.App/ClipboardGuard.cs`:

```csharp
using System.Diagnostics.CodeAnalysis;
using System.Runtime.InteropServices;
using System.Text;
using static Tuzat.App.Native.NativeMethods;

namespace Tuzat.App;

internal sealed record ClipboardItem(uint Format, byte[] Data);

internal sealed record ClipboardSnapshot(IReadOnlyList<ClipboardItem> Items);

internal sealed class ClipboardGuard : IDisposable
{
    private const int OpenAttempts = 5;
    private const int OpenRetryDelayMs = 20;

    private static readonly byte[] DwordZero = new byte[4];

    // Win+V history, cloud sync and clipboard managers skip content that carries these formats.
    private static readonly uint[] PrivacyFormats =
    [
        RegisterClipboardFormat("ExcludeClipboardContentFromMonitorProcessing"),
        RegisterClipboardFormat("CanIncludeInClipboardHistory"),
        RegisterClipboardFormat("CanUploadToCloudClipboard"),
    ];

    // SetClipboardData fails after EmptyClipboard unless the clipboard was opened with an owner window.
    private readonly NativeWindow _owner = new();

    public ClipboardGuard() => _owner.CreateHandle(new CreateParams { Parent = HWND_MESSAGE });

    public uint SequenceNumber => GetClipboardSequenceNumber();

    public bool TrySave([NotNullWhen(true)] out ClipboardSnapshot? snapshot)
    {
        snapshot = null;
        if (!TryOpen()) return false;
        try
        {
            var items = new List<ClipboardItem>();
            for (uint format = EnumClipboardFormats(0); format != 0; format = EnumClipboardFormats(format))
            {
                if (!IsGlobalMemoryFormat(format) || PrivacyFormats.Contains(format)) continue;
                if (ReadGlobal(GetClipboardData(format)) is { } data) items.Add(new ClipboardItem(format, data));
            }

            snapshot = new ClipboardSnapshot(items);
            return true;
        }
        finally
        {
            CloseClipboard();
        }
    }

    public bool TryReadText([NotNullWhen(true)] out string? text)
    {
        text = null;
        if (!TryOpen()) return false;
        try
        {
            nint handle = GetClipboardData(CF_UNICODETEXT);
            if (handle == 0) return false;
            nint pointer = GlobalLock(handle);
            if (pointer == 0) return false;
            try
            {
                string raw = Marshal.PtrToStringUni(pointer, (int)(GlobalSize(handle) / 2));
                int end = raw.IndexOf('\0');
                text = end >= 0 ? raw[..end] : raw;
                return true;
            }
            finally
            {
                GlobalUnlock(handle);
            }
        }
        finally
        {
            CloseClipboard();
        }
    }

    public bool TrySetText(string text) =>
        TryReplace([new ClipboardItem(CF_UNICODETEXT, Encoding.Unicode.GetBytes(text + '\0'))]);

    public bool TryRestore(ClipboardSnapshot snapshot) => TryReplace(snapshot.Items);

    public void Dispose() => _owner.DestroyHandle();

    private bool TryReplace(IReadOnlyList<ClipboardItem> items)
    {
        if (!TryOpen()) return false;
        try
        {
            if (!EmptyClipboard()) return false;
            bool complete = true;
            foreach (var item in items) complete &= TryWrite(item.Format, item.Data);
            foreach (var format in PrivacyFormats) TryWrite(format, DwordZero);
            return complete;
        }
        finally
        {
            CloseClipboard();
        }
    }

    private bool TryOpen()
    {
        for (int attempt = 1; ; attempt++)
        {
            if (OpenClipboard(_owner.Handle)) return true;
            if (attempt == OpenAttempts) return false;
            ThreadWait.Sleep(OpenRetryDelayMs);
        }
    }

    // GDI handles and owner-managed formats cannot be copied as plain memory; CF_DIB still keeps images.
    private static bool IsGlobalMemoryFormat(uint format) => format switch
    {
        2 or 3 or 9 or 14 => false,       // CF_BITMAP, CF_METAFILEPICT, CF_PALETTE, CF_ENHMETAFILE
        >= 0x80 and <= 0x8E => false,     // CF_OWNERDISPLAY and CF_DSP* formats
        >= 0x200 and <= 0x3FF => false,   // CF_PRIVATEFIRST..CF_GDIOBJLAST
        _ => true,
    };

    private static byte[]? ReadGlobal(nint handle)
    {
        if (handle == 0) return null;
        int size = (int)GlobalSize(handle);
        if (size == 0) return null;
        nint pointer = GlobalLock(handle);
        if (pointer == 0) return null;
        try
        {
            var data = new byte[size];
            Marshal.Copy(pointer, data, 0, size);
            return data;
        }
        finally
        {
            GlobalUnlock(handle);
        }
    }

    private static bool TryWrite(uint format, byte[] data)
    {
        nint handle = GlobalAlloc(GMEM_MOVEABLE, (nuint)Math.Max(data.Length, 1));
        if (handle == 0) return false;
        nint pointer = GlobalLock(handle);
        if (pointer == 0)
        {
            GlobalFree(handle);
            return false;
        }

        Marshal.Copy(data, 0, pointer, data.Length);
        GlobalUnlock(handle);
        if (SetClipboardData(format, handle) != 0) return true; // the clipboard now owns the memory

        GlobalFree(handle);
        return false;
    }
}
```

`src/Tuzat.App/FixSelectionAction.cs`:

```csharp
using Tuzat.Core;

namespace Tuzat.App;

internal static class FixSelectionAction
{
    private const int KeyC = 0x43;
    private const int KeyV = 0x56;
    private const int CopyTimeoutMs = 300;

    public static void Run(LayoutSwitcher layouts, InputSender input, ClipboardGuard clipboard, int restoreDelayMs)
    {
        if (FocusTracker.Current() is not { } focus || !input.ReleaseModifiers()) return;
        if (!clipboard.TrySave(out var saved)) return;

        uint before = clipboard.SequenceNumber;
        if (!input.Chord(VirtualKey.Control, KeyC)
            || !WaitForChange(clipboard, before)
            || !clipboard.TryReadText(out var text)
            || text.Length == 0)
        {
            if (clipboard.SequenceNumber != before) clipboard.TryRestore(saved);
            return;
        }

        var source = TextConverter.DetectSource(text, layouts.Map, layouts.SideOf(focus));
        if (!clipboard.TrySetText(TextConverter.Convert(text, layouts.Map, source)))
        {
            clipboard.TryRestore(saved);
            return;
        }

        // The target app reads the clipboard asynchronously; restoring too early pastes the old content.
        bool pasted = input.Chord(VirtualKey.Control, KeyV);
        if (pasted) ThreadWait.Sleep(restoreDelayMs);
        clipboard.TryRestore(saved);
        if (pasted) layouts.SwitchTo(focus, source.Opposite());
    }

    private static bool WaitForChange(ClipboardGuard clipboard, uint before)
    {
        long deadline = Environment.TickCount64 + CopyTimeoutMs;
        while (clipboard.SequenceNumber == before)
        {
            if (Environment.TickCount64 >= deadline) return false;
            ThreadWait.Sleep(10);
        }

        return true;
    }
}
```

````markdown
# Tuzat

Tuzat исправляет текст, набранный не в той раскладке. Работает по горячей клавише, без автоматического исправления.

- **Pause** — исправить последнее слово. Повторное нажатие возвращает слово обратно.
- **Shift+Pause** — исправить выделенный текст.

Программа работает в трее. Она не пишет набранный текст на диск и не отправляет данные в сеть.

## Установка

Запустите `Tuzat-Setup-<версия>.exe`. Права администратора не нужны. Программа ставится в `%LocalAppData%\Programs\Tuzat`.

## Настройки

Файл `%AppData%\Tuzat\settings.json`. Открыть его можно из меню в трее: «Открыть настройки». После изменений выберите «Перечитать настройки».

```json
{
  "fixLastWord": "Pause",
  "fixSelection": "Shift+Pause",
  "layouts": ["00000409", "00000419"],
  "clipboardRestoreDelayMs": 200
}
```

| Поле | Значение |
|---|---|
| `fixLastWord`, `fixSelection` | Горячая клавиша: модификаторы `Ctrl`, `Alt`, `Shift`, `Win` и клавиша `Pause`, `ScrollLock`, `Insert`, `Space`, `F1`–`F24`, `A`–`Z`, `0`–`9`. Пример: `Ctrl+Alt+F12`. Буквы, цифры и пробел нужно использовать с `Ctrl`, `Alt` или `Win`. |
| `layouts` | Пара раскладок (KLID). Примеры: `00000409` — английская (US), `00000419` — русская, `00000428` — таджикская, `00000843` — узбекская (кириллица). |
| `clipboardRestoreDelayMs` | Сколько ждать перед восстановлением буфера обмена после вставки. От 50 до 2000 мс. Увеличьте, если в медленном приложении вставляется старое содержимое буфера обмена. |

## Известные ограничения

- Окна, запущенные от администратора, не поддерживаются (UIPI).
- В некоторых терминалах и играх переключение раскладки может работать неточно.
- **Shift+Pause отправляет Ctrl+C.** В терминале без выделения это прерывает запущенную команду. В VS Code без выделения Ctrl+C копирует всю строку: отключите `editor.emptySelectionClipboard` или всегда выделяйте текст.
- Shift+Pause вставляет простой текст. Форматирование выделенного фрагмента (например, в Word) теряется.
- Поля пароля нельзя надёжно определить. Нажатия в них тоже попадают в буфер. Буфер хранится только в памяти, в нём не больше 64 нажатий.
- Неподписанный exe с перехватом клавиатуры может вызвать предупреждение антивируса или EDR.
- Форматы буфера обмена с отложенной отрисовкой (delayed rendering) могут не восстановиться.
````
